## 🌙 Tides & Currents

Tide and current predictions, offline, on every platform, powered by the open [Slackwater](https://slackwater.xyz) prediction engine and station database.

- [iOS](https://github.com/openwatersio/slackwater-ios) — iPhone, iPad & Apple Watch
- [Android](https://github.com/openwatersio/slackwater-android) — the Android app (in development)
- [Libraries](https://github.com/openwatersio/slackwater) — the prediction engine for TypeScript and Swift
- [API](https://api.openwaters.io/tides/) — hosted HTTP API for tides and currents
- [Database](https://github.com/openwatersio/slackwater-database) — a public database of tide and current stations
- [Signal K Plugin](https://github.com/openwatersio/signalk-tides) — tide and current predictions for your vessel's position
- [Homebrew](https://github.com/openwatersio/homebrew-tap) — `brew install` the Slackwater command-line tool

## ☀️ Sun & Moon

- [almanac](https://github.com/openwatersio/almanac) — an offline sun & moon engine: positions, rise/set, twilight, moon phase, eclipses. Twin Swift and TypeScript ports.

## 📡 AIS

- [Open Waters AIS](https://openwaters.io/ais/) — live vessel traffic from open government feeds and volunteer receivers: a [live map](https://openwaters.io/ais/vessels), aisstream.io-compatible streams, a REST API, and an MCP server. Contribute your receiver's data, or build on the [aiscast](https://github.com/openwatersio/aiscast) source and Signal K plugin.

## 🗺️ Charts

- [seamap](https://github.com/openwatersio/seamap) — a nautical-themed map with depths, seamarks, and hazards ([view it](https://openwaters.io/charts/seamap/))
- [seascape](https://github.com/openwatersio/seascape) — a map of the seafloor built from global open bathymetry ([view it](https://openwaters.io/charts/seascape/))
- [OpenWaters](https://github.com/openwatersio/OpenWaters) — an experiment in modern marine charts (alpha — not for navigation)
- [chart-catalog](https://github.com/openwatersio/chart-catalog) — a catalog of freely redistributable electronic navigational charts, pre-baked as vector tiles
- [enc-tiles](https://github.com/openwatersio/enc-tiles) — tools to produce vector tiles from Electronic Navigational Charts
- [tile-fonts](https://github.com/openwatersio/tile-fonts) — SDF glyph stacks for the Open Waters map styles

## 🌊 Bathymetry

- [crowd-depth](https://github.com/openwatersio/crowd-depth) — collect and share depth soundings from your vessel with crowd-sourced bathymetry programs

## 🧭 Navigation

- [maritime-zones](https://github.com/openwatersio/maritime-zones) — offline where-am-I and distance-to-territory lookups over the Marine Regions maritime boundaries, as FlatGeobuf tiles
- [coordinate-format](https://github.com/openwatersio/coordinate-format) — a TypeScript library to format coordinates as DMS and other formats

## 🧰 Tools

- [tippecanoe](https://github.com/openwatersio/tippecanoe) — a Docker image of tippecanoe for building vector tilesets
- [xtide](https://github.com/openwatersio/xtide) — a Docker image of XTide and its tide database utilities
