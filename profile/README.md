## 🌙 Slackwater

Tide and current predictions, offline, on every platform. Slackwater is the name for everything we publish about tides and currents, and it all runs on one open prediction engine. Read the docs at [openwaters.io/tides/slackwater](https://openwaters.io/tides/slackwater/).

- [Slackwater for iPhone](https://slackwater.xyz) — the iOS app, with Apple Watch and widgets ([source](https://github.com/openwatersio/slackwater-ios))
- [Slackwater for Android](https://github.com/openwatersio/slackwater-android) — the Android app
- [slackwater](https://github.com/openwatersio/slackwater) — the prediction engine for TypeScript and Swift
- [CLI](https://github.com/openwatersio/slackwater/tree/main/packages/cli) — predictions in your terminal: `brew install openwatersio/tap/slackwater`
- [API](https://api.openwaters.io/tides/) — hosted HTTP API for [tides](https://api.openwaters.io/tides) and [currents](https://api.openwaters.io/currents)
- [React components](https://github.com/openwatersio/slackwater/tree/main/packages/react) — tide predictions in your web app
- [slackwater-database](https://github.com/openwatersio/slackwater-database) — a public database of tide and current stations
- [signalk-tides](https://github.com/openwatersio/signalk-tides) — a SignalK plugin that publishes tide predictions for your vessel's position

## ☀️ Sun & Moon

- [almanac](https://github.com/openwatersio/almanac) — an offline sun & moon engine: positions, rise/set, twilight, moon phase, eclipses. Twin Swift and TypeScript ports.

## 📡 AIS

- [Open Waters AIS](https://openwaters.io/ais/) — live vessel traffic from open government feeds and volunteer receivers: a [live map](https://openwaters.io/ais/vessels), aisstream.io-compatible streams, a REST API, and an MCP server. Contribute your receiver's data, or build on the [aiscast](https://github.com/openwatersio/aiscast) source and SignalK plugin

## 🗺️ Bathymetry

- [seascape](https://github.com/openwatersio/seascape) — a map of the seafloor built from global open bathymetry
- [seamap](https://github.com/openwatersio/seamap) — a nautical-themed map with depths, seamarks, and hazards
- [crowd-depth](https://github.com/openwatersio/crowd-depth) — collect and share depth soundings from your vessel with crowd-sourced bathymetry programs

## 🧭 Charts & Navigation

- [OpenWaters](https://github.com/openwatersio/OpenWaters) — an experiment in modern marine charts (alpha — not for navigation)
- [enc-tiles](https://github.com/openwatersio/enc-tiles) — tools to produce vector tiles from Electronic Navigational Charts
- [chart-catalog](https://github.com/openwatersio/chart-catalog) — a catalog of freely redistributable electronic navigational charts, pre-baked as vector tiles
- [tile-fonts](https://github.com/openwatersio/tile-fonts) — SDF glyph stacks for the Open Waters map styles
- [maritime-zones](https://github.com/openwatersio/maritime-zones) — offline where-am-I and distance-to-territory lookups over the Marine Regions maritime boundaries, as FlatGeobuf tiles
- [coordinate-format](https://github.com/openwatersio/coordinate-format) — a TypeScript library to format coordinates as DMS and other formats
